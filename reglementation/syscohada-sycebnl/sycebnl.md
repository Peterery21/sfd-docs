## Choix de produit (hors réglementation)

- Activer un jeu de comptes SYCEBNL séparé du jeu SYSCOHADA par type d'entité ; mapping par rôle (fonds affectés, dotations, cotisations) : conception produit.
- Les exemples du guide sont illustratifs : un numéro de compte vu dans un exemple n'est pas une obligation d'utiliser ce compte pour tout cas.

## Lacunes / à confirmer

- Texte intégral de l'Acte SYCEBNL et son annexe (422 p.) : NON LU. Gros PDF probable sur https://www.ohada.com/uploads/actualite/6692/SYSCEBNL.pdf (taille inconnue, non téléchargé).
- Plan de comptes SYCEBNL officiel complet (classes, libellés) : NON LU ; seuls les comptes du guide sont cités.
- Seuils du système minimal de trésorerie SYCEBNL : NON TROUVÉ.
- Règles de résultat de l'EBNL (excédent/déficit, comptes 13) : NON TROUVÉ dans le guide.
- Délais d'établissement/approbation, conservation : NON TROUVÉ pour le SYCEBNL.
