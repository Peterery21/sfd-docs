# Glossaire

Définitions d'usage dans cette documentation (explicatives ; la valeur réglementaire est dans les textes cités par zone).

| Terme | Sens |
|---|---|
| SFD | Système financier décentralisé (terme UEMOA). Équivalents : EMF (CEMAC), COOPEC / IMF (RDC). |
| EMF | Établissement de microfinance (CEMAC, COBAC). |
| COOPEC | Coopérative d'épargne et de crédit (RDC, loi 002/2002). |
| IMF | Institution de microfinance (RDC, loi 11/020). |
| BCEAO / CB-UMOA | Banque centrale des États de l'Afrique de l'Ouest / Commission bancaire de l'UMOA. |
| BEAC / COBAC | Banque des États de l'Afrique centrale / Commission bancaire de l'Afrique centrale. |
| BCC | Banque centrale du Congo. |
| UEMOA / UMOA | Union économique et monétaire ouest-africaine / Union monétaire ouest-africaine. |
| CEMAC / UMAC | Communauté économique et monétaire de l'Afrique centrale / Union monétaire de l'Afrique centrale. |
| OHADA | Organisation pour l'harmonisation en Afrique du droit des affaires. |
| AUDCIF | Acte uniforme relatif au droit comptable et à l'information financière (SYSCOHADA révisé, 2017). |
| AUSCGIE | Acte uniforme relatif au droit des sociétés commerciales et du GIE (révisé 2014). |
| SYSCOHADA | Système comptable OHADA ; SYCEBNL : système comptable des entités à but non lucratif. |
| RCSFD | Référentiel comptable spécifique des SFD (UEMOA, Instr. BCEAO 025-02-2009). Norme produit : `RCS_SFD`. |
| PCEMF | Plan comptable des établissements de microfinance (CEMAC, BEAC 2010). Norme produit : `COBAC`. |
| PCCI | Plan comptable des COOPEC / IMF (RDC, institué par Instr. BCC 006). Norme produit : `PCCI`. |
| GCEC | Guide comptable des établissements de crédit (RDC, banques). Norme produit : `GCEC`. |
| DAT | Dépôt à terme. |
| TEG | Taux effectif global (taux d'intérêt + frais et accessoires obligatoires). |
| FPP / fonds propres | Fonds propres prudentiels (base des ratios prudentiels). |
| LBC/FT | Lutte contre le blanchiment de capitaux et le financement du terrorisme. |
| KYC | Connaissance du client (identification et vérification). |
| Rôle comptable | Fonction métier d'un compte (ex. CAISSE, COMPTE_VUE) indépendante de la norme ; chaque norme associe un numéro de compte à chaque rôle (`regles-vers-produit/`). |
| IMPOSÉ PAR TEXTE / SILENCE DU TEXTE / CHOIX DE PRODUIT | Classement des réponses : un texte lu impose / aucun texte lu ne tranche / décision d'implémentation. |
| Confiance HAUTE / MOYENNE / BASSE | Texte primaire lu / source secondaire ou lecture partielle / rapporté à confirmer. |
| ✔ ◐ ✘ ? | Vérification indépendante : 2 sources / 1 source / infirmé (corrigé) / non retrouvé. |
