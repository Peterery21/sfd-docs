## Choix de produit (hors réglementation)

- Clôture journalière : le RCSFD impose l'enregistrement le jour même et l'impossibilité de rouvrir une journée clôturée, pas un « wizard » de clôture journalière ; son contenu (contrôles de caisse, rapprochements) est un choix produit.
- Clôture mensuelle : le texte exige la balance mensuelle et les données mensuelles prudentielles ; les contrôles d'une clôture mensuelle sont un choix produit.
- Clôture annuelle : étapes (inventaires, régularisations, affectation) sont réglementaires dans le fond mais la séquence logicielle est un choix produit.
- Périodicité des arrêtés intermédiaires internes (hors décadaire/mensuel/trimestriel requis) : décision du SFD.

## Lacunes / à confirmer

- Instruction n°020-12-2010 (annexe des indicateurs), n°018-12-2010 (rapport annuel), n°001-02-2018 (états financiers) : contenu détaillé non lu.
- Réévaluation des devises / écarts de change à la clôture : NON TROUVÉ.
- Calendrier précis de la décadaire (D) : le RCSFD définit le code mais le texte lu n'indique pas quels états sont décadaires.
- Version développée du RCSFD : non lue.
