# CEMAC / BEAC / COBAC — textes fondateurs de la microfinance

- Zone : CEMAC (Cameroun, Centrafrique, Congo, Gabon, Guinée équatoriale, Tchad). Autorités : Comité ministériel de l'UMAC, BEAC, COBAC.
- Norme comptable produit : COBAC = PCEMF (Plan comptable des établissements de microfinance, janvier 2010).
- Rédaction : 2026-10-13, agent de recherche (Claude). Toutes les vérifications sont à `?` (voir FORMAT.md).
- Méthode : texte primaire lu (PDF texte ou OCR local) quand l'accès a été possible ; sinon source secondaire signalée (confiance MOYENNE/BASSE). OCR en anglais sur texte français (accents perdus) : articles et chiffres recoupés, un chiffre OCR douteux est signalé.
- ATTENTION classes : le PCEMF place la clientèle en classe 3 (crédits 30-32, souffrance 33, dépôts 35-37, autres comptes 38, provisions 39) ; capital en classe 10. Aucun compte RCSFD/UEMOA (classe 2, 25xxxx, 57111…) ne doit être transposé. Voir `sfd-docs/AUDIT_PLAN_COMPTABLE_ZONE_SECTEUR.md`.
- Fichiers : `comptabilite.md`, `epargne.md`, `credit.md`, `parts-sociales.md`, `clotures.md`, `prudentiel.md`, `lbc-ft.md`, `taux-usure.md`, `dormants-conservation.md`, `questions-ouvertes.md`, `regles-vers-produit-cemac.md`.

## 4. Points d'attention pour le produit

1. Le PCEMF (2010) décrit les règles de classification/provisionnement de l'ancien Règlement EMF 2002/18 (45 jours, 15/45/75/100 %…). Elles sont remplacées par R-2017/07 dont le texte n'a pas pu être lu : ne pas les coder comme règles en vigueur sans lecture de R-2017/07 (voir `credit.md`).
2. L'inventaire local `sfd-docs/refs/PCEMF_PLAN_COMPTES_INVENTAIRE.md` est incomplet : il omet les comptes 30-31 (crédits LT/MT), 164 (provisions pour risques généraux), 443 (dividendes), 444 (ristournes), 477 (ajustement devises) ; son 340/341 diffère du préambule du PCEMF (341/342). Les comptes cités ici viennent du PDF PCEMF lu (table des comptes et commentaires de fonctionnement).
3. Non lus : 01/17, R-2017/01 à /09, R-2017/07 et /08, texte LBC/FT 2024. Voir « Lacunes » de chaque fichier.
